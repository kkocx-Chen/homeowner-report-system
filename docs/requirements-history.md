# 需求與決策摘要

這份文件以摘要記錄專案功能與重要決策，讓往後維護時能理解每次改動的背景。它不保存聊天逐字稿、密碼、Token、客戶聯絡資訊或其他敏感資料。

## 2026-08-06 至 2026-08-08：第一版

- 建立「時上 S」屋主銷售進度頁面，內容以手機閱讀與 LINE 內建瀏覽器為優先。
- 主要資訊為賞屋／帶看人數、物件單價與近期成交、591 瀏覽表現、專員分析。
- 賞屋區提供本週帶看時間與有望買方；有望買方可查看進度、複看時間、追蹤狀態或無效原因。
- 591 卡片可前往物件頁，並呈現電腦與手機瀏覽拆分數字。
- 後台可維護所有公開內容、帶看時間、有望買方排序、分析文字，以及發布含圖片的新公告。
- 公告不會在進入網站時自動彈出，統一由右上角公告中心手動開啟；新公告發布後 24 小時內顯示未讀數量，期滿後公告仍保留在歷史列表。
- 後台保留全部公告歷史，並可個別控制公告是否繼續於前台顯示。
- 頂端公告左側提供斡旋入口，以角標顯示目前筆數；點開後顯示收件時間、出價、斡旋金、處理狀態與進度備註。
- 後台可新增、更新與刪除斡旋紀錄，資料與其他屋主回報內容共同保存及備份。
- 收斡旋後，賞屋人數上方顯示精簡的代書流程卡片，前台只顯示目前最新階段與日期，高度依內容自然撐開；後台仍可從收斡旋、見面談、簽約、用印、完稅、過戶與交屋中更新目前階段，並調整日期或暫時隱藏卡片。
- 案件解約後，前台關閉代書流程卡片，並在賞屋人數右側顯示民國年月日與解約時間；後台可調整解約通知開關及時間，通知開啟時自動關閉代書流程。
- 正式站部署於 VPS，以 Nginx 反向代理到 Node.js 服務；正式服務名稱為 `report-kkocx`。

## 維護原則

- 每次程式功能變更都要更新 `CHANGELOG.md`，使用清楚的 Git commit 訊息並推送至私有 GitHub repository。
- Git 只保存程式碼、文件與可公開的設定範本；即時資料與上傳圖片由 VPS／Dropbox 備份保存。
- 推送到 GitHub 不會自動部署。只有在確認後執行獨立部署流程，才會影響正式網站。
